# Conditional specialist and runtime lanes

Read only after an explicit matching platform/provider/craft requirement. This is a routing catalog, not a checklist to load every skill. The installed support manifest records availability, never production state. Missing selected capability is a blocker; finish reachable preparation without silent substitution.
