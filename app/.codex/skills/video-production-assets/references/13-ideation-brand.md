# 아이디어 발상·브랜드 영상

## 실행 절차
1. 소재가 없거나 광고/브랜드 영상이면 제품·관객의 구체적 자료와 다른 분야의 관찰 자료를 구분해 모은다. 사실과 가상을 표시한다.
2. 영상 주제·시놉시스 탐색을 요청받았을 때는 [탐색 계약](../../orchestrating-video-preproduction/references/video-direction.md#discovery-topic-and-synopsis)을 읽어 채널/관객 적합성 우선 추천·개수·선택·확정 입력 생략을 적용한다. 트렌드는 확인 가능한 출처/시점이 있는 보조 근거이며 일반 콘셉트 요청에 탐색 단계를 강제하지 않는다.
3. 관객 문제×제품 증거×뜻밖의 상황을 조합해 서로 다른 콘셉트 후보를 만든다. 각 후보에 한 문장 약속·대표 장면·제작 제약·다른 후보와 구별되는 판단 포인트를 붙인다. 탐색 계약이 적용되지 않으면 명시된 후보/앵글 수를 지키고, 미지정이면 요청 범위에 필요한 탐색 폭으로 수를 정한다. 텍스트 후보 수를 실제 이미지/영상 출력 수로 승계하지 않는다; 생성 수·설정·비용은 별도 실행 승인 범위다.
4. 초기 조합과 수정 단계를 구분한다. 숙성은 사람의 발상 과정에 대한 설명으로 다루고 에이전트가 무의식을 가동했다거나 기다린 뒤 자동 통찰을 얻었다고 주장하지 않는다.
5. 브랜드가 지향하는 가치와 실제 제공 가능한 경험을 분리한다. 로고·색만 맞추는 것으로 브랜드 일치 판정을 끝내지 않는다.
6. 품질을 판단할 수 있는 제품 사용·비교·조건·한계를 화면에 넣는다. 광고 분위기로 실제 품질 정보를 대체하거나 가짜 후기를 만들지 않는다.
7. 구매 전·사용 중·구매 후 가운데 영상이 다루는 고객 순간을 정한다. CTA가 향하는 다음 경험과 영상의 약속이 맞는지 확인한다.
8. 관객 관련성·증거·기억할 장면·브랜드 일치·실행 가능성으로 후보를 비교한다. 선택 이유를 설명하되 성과가 검증됐다고 주장하지 않는다.

## 입력·산출물
확정 브리프와 해당 제작 원장을 입력받고 아래 템플릿을 채워 인계한다.

## 근거와 한계
37~40번 첨부 정상 본문을 선별 탐색했다. 37: 자료 수집과 재조합·숙성·검토; 38: 브랜드 비전; 39: 실제 품질 정보와 외부 정보; 40: 고객 경험과 기대. 적용 절차는 독자적으로 재구성했다.
