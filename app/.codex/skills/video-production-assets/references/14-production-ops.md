# 제작 일정·예산·에셋 운영

## 실행 절차
1. 필요한 역할·장소·장비·참조 파일·촬영/생성/편집 단계를 명시한다. 제작 방식에 없는 부서나 절차는 N/A로 둔다.
2. 장소·조명 세팅을 기준으로 촬영 순서를 묶고 장면·샷 ID를 연결한다. 세팅·리허설·촬영·이동·정리 시간을 분리한다.
3. 비용은 수량×단가, 통화, 확정/견적/추정, 출처로 기록한다. AI 생성은 요청당 비용·예상 재시도·상한·중단 기준을 적는다. 실제 요금이 필요하면 현재 공급자 정보로 확인한다.
4. 필요한 실제 파일은 asset_registry에 등록한다. 계획 에셋은 경로를 null로 두고 상태 planned로 기록한다. 장소·소품·인물·룩 참조의 버전과 사용 샷을 연결한다.
5. 파일명은 project_id/shot_id/version/take를 포함하고 원본·선택 테이크·편집본을 구분한다. 파일 교체 시 원장을 갱신하고 기존 선택 버전을 보존한다.
6. 실제 사용하는 음악·사진·폰트·인물 등의 이용 가능 범위와 출처를 기록한다. 없는 자료에 불필요한 승인 절차를 만들지 않는다. 현장 위험 작업은 실제 제작 책임자의 준비 사항에 포함한다.
7. 입력 버전이 바뀐 산출물과 그 종속 산출물을 stale로 표시한다. 실패한 샷은 단순 반복 대신 조치·한도·대체 샷을 결정한다.
