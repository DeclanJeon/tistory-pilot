# 작은 배달 — 제작 계획

project_id: glove-return-20s / version: 0.1 / status: draft

검수 대상은 이 문서와 project.json뿐이다. 영상·그림 스토리보드·모델·애니매틱·음원은 제작하지 않았다. 모든 시간, ID, 인물·소품 고정값은 project.json을 기준으로 한다. 아래 각 절은 스킬의 해당 모듈 템플릿을 채운 통합 에셋이다. 공통 입력 버전은 0.1이며, 산출물 의존성은 JSON artifacts에 기록했다.

## brief — A01

대상 관객: 출퇴근 중 짧은 무음 영상을 보는 사람.
핵심 약속: 작은 도움을 알아보는 순간의 따뜻함을 행동만으로 전달한다.
형식/길이/화면비/fps: 오리지널 3D 애니메이션 / 20초 / 9:16 / 24fps, 총 480프레임. 제안 해상도 1080×1920.
필수 증거 장면: 장갑 낙하, 로봇의 반환 시도, 통근자의 시선 전환, 손에서 손으로 장갑 이동.
제작 제약과 대체안: 인물 두 명(CH01·CH02), 정류장 한 곳(S01/LOC01). 버스나 군중 대신 오른쪽 대기 지점으로 서두르는 동선. 완전 무음; 안내문·자막도 사용하지 않는다.
가정: 3D 단순화 스타일·아침·플랫폼 미지정·24fps·해상도는 제안값. silent를 대사뿐 아니라 모든 오디오 없음으로 해석했다.
완료 기준: 정확히 20초, 두 인물과 한 장소, 작은 화면에서도 장갑 주인이 분명하고 반환 선택을 이해할 수 있음.
미확인 사항: 최종 플랫폼과 실제 제작 도구. 다음 인계: A02·A03, 입력 A01 v0.1.

## story — A02

로그라인: 작은 로봇 모루는 급히 걸어가는 통근자에게 떨어진 장갑을 돌려주려 하지만 키가 작아 눈에 띄지 않는다. 상대의 시선에 장갑을 올리는 선택으로 잠깐의 배려를 얻는다.
주제 질문: 바쁜 걸음을 멈추게 하는 것은 얼마나 큰 행동이어야 할까?
욕망/필요/결함: 모루는 반환을 원하고, 상대가 볼 수 있는 위치를 찾아야 한다. 처음에는 뒤에서 손만 내민다. 통근자는 대기 지점으로 서두르며 주변을 못 본다. 실패 비용은 장갑을 잃어버리는 작은 불편이다.
선택한 구조와 이유: 발견→실패한 시도→전술 전환→반환의 인과 비트. 20초에 불필요한 장편 단계를 추가하지 않는다.

| beat_id | 원인 | 선택/행동 | 결과 | 가치 전후 | 관객 감정 | 길이 예산 |
|---|---|---|---|---|---|---|
| B01 | 급한 걸음에 장갑 낙하 | 모루가 멈춰 봄 | 목표 발생 | 무관심→발견 | 기대 | 0–3초 |
| B02 | 주인이 놓침 | 집어 오른손에 내밈 | 반환 준비 | 발견→도움 의지 | 응원 | 3–6초 |
| B03 | 키가 작아 안 보임 | 짧은 걸음으로 따라감 | 여전히 못 알아봄 | 시도→막힘 | 조마조마 | 6–10초 |
| B04 | 주인이 대기 위치에 정지 | 장갑을 시선 높이에 올림 | 통근자가 돌아봄 | 막힘→연결 | 안도 | 10–14초 |
| B05 | 시선이 만남 | 통근자가 몸을 낮춰 받음 | 장갑 반환 | 연결→감사 | 따뜻함 | 14–18초 |
| B06 | 도움이 완료됨 | 모루가 빈손을 흔듦 | 함께 정류장에 남음 | 감사→여운 | 미소 | 18–20초 |

미확인 사항: 감정 가독성은 애니매틱에서 확인. 다음 인계: A03, 입력 A02 v0.1; 생성 B01–B06.

## screenplay — A03

S01 / LOC01 소형 버스 정류장 / 부드러운 아침.
목적: 급한 통근자와 작은 로봇이 반환을 통해 관계를 맺는다.
화면 행동: B01–B06과 동일한 순서로 장갑 낙하→집기→따라가기→높이 들기→받기→빈손 흔들기. CH02는 오른쪽 기둥 앞에서 정지하며 프레임 밖으로 나가지 않는다. 반환 후에도 같은 대기 위치에 남는다.
대사: 없음. 내레이션: 없음. 소리/침묵: AU01, 0–20초 완전 무음.
예상 길이와 측정 상태: 행동 배정 합계 20초; 실제 재생·연기 시간은 미측정. 근거: CL01 창작.
미확인 사항: 실제 블로킹 속도. 다음 인계: A04·A06, 입력 A03 v0.1; 생성 S01.

## ai-handoff — A10

참조: CH01·CH02·LOC01·PR01·LOOK01은 project.json의 설계 SSOT. 실제 모델·승인된 이미지 파일은 없다. 다음 제작자는 동일 파일명을 가진 가상 참조를 만들지 말고 캐릭터 턴어라운드, 장갑, 정류장 마스터, 룩 테스트를 실제로 제작·검토한 뒤 매핑해야 한다.
각 SH01–SH06의 완성 프롬프트는 project.json shots[].prompt에 있다. 대상/환경→초기 상태→주 행동→카메라→조명→끝 상태→고정 규칙 순서로 구성했다. 시작·끝 상태와 손 소유권은 같은 원장을 따른다.
도구 지원 확인: 도구 미선정, 참조·세로 화면·길이·오디오 차단·카메라·프레임 제어 모두 미확인. 특정 API나 seed 일관성을 약속하지 않는다. 수령 샷이 실패하면 접촉 포즈를 고정한 3D 키프레임 경로로 대체한다.
생성 길이/편집 길이/핸들: A06 표·JSON 참조. 출력 프레임 길이가 다르면 핸들을 확보하고 최종 480프레임으로 편집한다.
검수 실패 위치·수정 변수: 아직 생성 없음, 실패 타임코드 없음. 향후 `shot_id / source time / 문제 / 바꾼 단일 변수 / 결과 파일 / 버전`으로 기록. 반환 손 오류면 손 소유권만 수정하고 룩·카메라를 유지한다.
미확인 사항: 실제 참조·도구 지원은 생성 착수 전 해결 필요. 다음 인계: A11 및 선택한 제작 도구, 입력 A05–A08 v0.1. 이 문서의 작성은 영상 생성·게시를 뜻하지 않는다.
